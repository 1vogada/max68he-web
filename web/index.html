      Analog curve

      Left to right: key depth, 0 to 4 mm (the shaded part is the dead zone). Bottom to top: how far the stick or trigger moves. Drag a point to shape your own curve.

      Gamepad response

      A full diagonal gives full sideways and full forward at once, instead of staying on the circle a real stick draws. Good for games that move slower on diagonals.

      Two opposite keys (A and D): the one pressed deeper wins outright, instead of the two cancelling out.

      Macros

      The keyboard types it by itself, no app needed. On a key it plays once per press; Macro3:hold repeats while held, Macro3:toggle starts and stops it.

      Play a sequence

      How to write it

      One step per line or separated by ;, # starts a note.

      • 120ms, 1.5s: wait before the next step
      • W down, W up: hold or let go of a key; Ctrl+Shift+Esc down for a chord
      • Space tap, Ctrl+C tap, A tap 50ms: press and let go (held 20 ms unless given)
      • release: let go of everything
      • click L (L, R, M), mouse down R, mouse up R, move 10 -5 (right 10, up 5 at once), wheel 2

      Glide the pointer instead of jumping: move DX DY over TIME [curve], 1 ms to 65.5 s.

      • move 300 0 over 500ms: steady speed (linear)
      • move 0 -200 over 1s ease out: ease in starts slow, ease out ends slow, ease inout both; a strength after it, ease in 3 (0.3 to 8, default 2)
      • move 150 150 over 400ms sine, … smooth: gentle start and end
      • move 400 0 over 1s expo 8: exponential, -20 to 20 (not 0, default 5); minus eases out
      • move 200 0 over 800ms curve points 0,0 64,200 192,230 255,255: your own curve, 4 points time,distance 0 to 255

      A glide runs on its own: the next step follows straight away (its wait counts from the glide's start), up to 4 glides at once. The sequence ends when the last glide is done.

      Up to 512 steps. Everything is let go at the end, so end with a wait to keep a key held.

      The keyboard plays it on its own clock, so timing is exact. In online games with anti-cheat, automated input can break their rules.

      Texts

      Up to 119 bytes each: plain letters, digits and punctuation take 1, special characters (é, °, ʖ, emoji…) take 2 to 4. Plain characters are typed as on a US keyboard layout.

      Special characters ( ͡° ͜ʖ ͡°): one-time setup

      The keyboard can only press keys, so for a special character it types the system's Unicode code for it. Which system is set in General settings → Firmware options.

      Windows (once, then sign out and back in): run this in PowerShell, then it works in most programs.

      Set-ItemProperty -Path 'HKCU:\Control Panel\Input Method' -Name EnableHexNumpad -Value '1'

      Linux: works in GTK / IBus programs as it is. macOS: add the "Unicode Hex Input" keyboard in System Settings → Keyboard → Input Sources and switch to it.

      Each special character takes about a tenth of a second to type.

      Keyboard options

      Firmware options

      Fn + Home / Del / PgUp / PgDn picks Fn layer 1 / 2 / 3 / 4. Off: the pick stays until you pick another. On: it only applies while you hold that key.

      The keyboard stops drawing lighting effects and the LEDs stay off, so all its time goes to the keys. Game mode and calibration still light up.

      The lighting fades to this level first, then turns off at "Lighting off after idle". A dim time at or after the off time is skipped. Any key wakes it.

      After you let go, a key stays down this long, so a key that flickers on release isn't sent twice. Presses are never delayed. Off for the fastest rapid trigger.

      The keyboard reports itself as a plain 6-key boot keyboard, without n-key rollover, for a BIOS, a console or a KVM switch that doesn't see keys otherwise. Only 6 keys at once (plus modifiers) reach the PC.

      Reset all keyboard settings
